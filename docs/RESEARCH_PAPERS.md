# Research Papers to Cite

This document collects recommended research papers, short summaries, and citation references relevant to phishing detection, brand/logo analysis, and extension security. Use these citations in reports, papers, or documentation accompanying the project.

## Phishing and Brand Detection

- PhishIntention — USENIX Security 2022
  - Short: Intent-aware phishing detection that focuses on page intent signals beyond lexical URL features.
  - Link: https://www.usenix.org/conference/usenixsecurity22/presentation/liu-ruofan

- PhishLLM — USENIX Security 2024
  - Short: Large-language-model approaches for phishing detection and analysis.
  - Link: https://www.usenix.org/conference/usenixsecurity24/presentation/liu-ruofan

- Phishpedia — USENIX Security 2021
  - Short: Large-scale dataset and methods for phishing page classification and analysis.
  - Link: https://www.usenix.org/conference/usenixsecurity21/presentation/lin

- LogoMorph — USENIX Security 2024
  - Short: Logo morphing and visual-brand evasion techniques; implications for visual-brand detectors.
  - Link: https://www.usenix.org/conference/usenixsecurity24/presentation/hao-qingying

- PhishDecloaker — USENIX Security 2024
  - Short: Techniques for deobfuscating and revealing phishing infrastructure and content.
  - Link: https://www.usenix.org/conference/usenixsecurity24/presentation/teoh

## Extension Security and Web Evaluation

- Hulk — USENIX Security 2014
  - Short: Large-scale analysis of malicious extension behaviors and ecosystem risks.
  - Link: https://www.usenix.org/conference/usenixsecurity14/technical-sessions/presentation/kapravelos

- WebEval — USENIX Security 2015
  - Short: Methodologies for large-scale web security and content assessment.
  - Link: https://www.usenix.org/conference/usenixsecurity15/technical-sessions/presentation/jagpal

- Arcanum — USENIX Security 2024
  - Short: Recent work on extension or web platform threats and defenses.
  - Link: https://www.usenix.org/conference/usenixsecurity24/presentation/xie-qinge

## Other Useful References

- Phishing datasets and feeds (PhishTank, OpenPhish, URLhaus) — see dataset providers for provenance and terms of use.
- Brand/logo detection literature (academic CV and security papers on logo recognition and forgery).

## Citation suggestions

When citing these works in reports or papers, include the full paper metadata from each conference page. Example short citation formats:

- Liu et al., "PhishIntention", USENIX Security, 2022. https://www.usenix.org/conference/usenixsecurity22/presentation/liu-ruofan
- Liu et al., "PhishLLM", USENIX Security, 2024. https://www.usenix.org/conference/usenixsecurity24/presentation/liu-ruofan
