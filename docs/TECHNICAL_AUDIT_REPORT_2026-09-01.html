1. Project overview

Project title: Secure Browser Extension.

Problem solved: phishing pages, credential-harvesting forms, unsafe downloads, weak cookie settings, password reuse, and risky installed-extension exposure are difficult for ordinary users to assess while browsing.

Main objective: build a privacy-first Chrome extension that detects suspicious browser activity through explainable evidence rather than a black-box warning.

Intended users: general Chrome users, students, evaluators, and security-aware users who need understandable browsing-risk alerts.

Expected final product: Chrome MV3 extension, React popup/dashboard, FastAPI service, MongoDB-backed sanitized evidence, trained URL/text/visual models, reports, chatbot, and evaluation results.

What makes it useful: it combines URL, form, brand/domain, text, download, cookie, password, and extension-permission evidence. It is designed to explain why a page is risky and to minimize sensitive-data collection.

Implemented features

  • Local URL, form, and brand/domain rule scoring.
  • Dynamic FormGuard logic using DOM observers.
  • React popup/dashboard source UI and local Chrome storage.
  • Download, cookie, password, and extension-exposure scanner source modules.
  • FastAPI health, analysis, evidence, reports, chat, and placeholder reputation endpoints.
  • JSONL fallback persistence, MongoDB repository design, test fixtures, and automated tests.

3. What has actually been completed

Evidence engine and local trust score

Purpose: turn page metadata into a structured evidence object with scores, verdict, reasons, and timeline. Input: URL, form metadata, page labels/headings, iframes. Processing: URL/form/brand rules plus weighted fusion. Output: trust score and explainable reasons. Status: implemented in source but blocked in installed build.

Files: extension/src/lib/evidence/schema.js, extension/src/content/pageScanner.js, extension/src/lib/scoring/finalScore.js.

URL analyzer

Scores HTTP, IP hosts, embedded credentials, punycode, suspicious TLDs, unusual subdomains, long/random domains, encoded characters, phishing-themed tokens, brand mismatch, and redirects. It is deterministic rule logic, not trained XGBoost.

Files: urlScore.js, ml/url_model_stub.py.

FormGuard

Detects password fields, hidden fields, cross-origin/cross-domain actions, HTTP submission, GET password forms, disabled autocomplete, action changes, overlays, and iframe login forms. Mutation observers re-scan relevant DOM changes without normally reading typed password values for page evidence.

Files: contentScript.js, pageScanner.js, formScore.js.

BrandGuard

Uses a fixed brand dictionary to compare claimed brands in sanitized page cues with actual domains and form destinations. It produces expected-domain data and mismatch explanations. It does not use a trained NLP or visual model.

Files: brandProfiles.js, brandGuardScore.js.

Local security modules

  • Download scanner: checks risky file extensions, double extensions, right-to-left override characters, source wording, and Chrome danger state. No file content is read/uploaded.
  • Cookie scanner: hashes cookie names and scores Secure, HttpOnly, SameSite, and expiry after optional permission.
  • Password analyzer: estimates strength, stores a derived fingerprint for reuse, and includes an optional HIBP k-anonymity path.
  • Extension scanner: scores permissions, host access, development/sideload installation, and changes. It correctly avoids claiming proof of data theft.

Files: scannerService.js, securityUtils.js, passwordAnalyzer.js, scanStorage.js.

19. Five-to-ten-minute presentation explanation

Secure Browser Extension is a privacy-focused Chrome extension designed to detect phishing and browser-security risks. Phishing pages often look legitimate, especially when they copy a known brand or ask users for credentials. The project addresses this by collecting safe evidence locally from the URL, form structure, domain, and sanitized page cues.

The main advanced feature is FormGuard. It checks whether password forms submit to another domain, appear dynamically, use HTTP, hide credential inputs, or change their action after loading. BrandGuard then checks whether a page claiming a known brand is hosted on an expected domain. The extension converts these signals into a trust score and an explanation.

The project uses React for the interface, Chrome MV3 for browser integration, and FastAPI for backend services. It also includes a JSONL/MongoDB persistence design and ML-ready rule stubs. At present, this is an explainable security prototype, not a complete AI product. The honest status is 45% because a fresh extension build has a content-script packaging error, the ML models are not trained, and evaluation/deployment work remains.

The next milestone is fixing the MV3 bundle and proving a current live phishing scan in Chromium. After that, the backend can be wired to the extension, privacy gaps can be fixed, and trained models can be evaluated using precision, recall, F1, and PR-AUC.
